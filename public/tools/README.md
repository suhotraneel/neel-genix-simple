# Tools Logos Directory

Upload your tool logo images/SVGs into this folder.

### Supported Tool IDs:
- `figma.svg` or `figma.png` (Figma)
- `photoshop.svg` or `photoshop.png` (Adobe Photoshop)
- `illustrator.svg` or `illustrator.png` (Adobe Illustrator)
- `after-effects.svg` or `after-effects.png` (After Effects)
- `spline.svg` or `spline.png` (Spline)
- `notion.svg` or `notion.png` (Notion)
- `miro.svg` or `miro.png` (Miro)
- `cursor.svg` or `cursor.png` (Cursor)
- `webflow.svg` or `webflow.png` (Webflow)

You can upload files with `.svg`, `.png`, `.webp`, or `.jpg` extensions. Once uploaded, let me know and I will hook them up directly to the Tools showcase!
